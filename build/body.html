월간 예약 · 반복 · JSON가능이 기기에 저장. JSON은 PC 스케줄러용.
조회·좋아요·댓글·저장 수집직접 입력공식 API 실시간 조회는 앱 자격·서버가 필요합니다. 숫자를 붙여넣으면 분석은 자동.
예약 시각 자동 게시PC 스케줄러브라우저 탭이 닫히면 아무것도 못 합니다. JSON을 PC가 읽어 알림·업로드 준비.
인스타·틱톡 공식 OAuth 연동불가비즈니스 계정·앱 심사·서버 콜백 필요. 정적 앱은 자격 증명을 안전히 보관할 수 없습니다.
DM·댓글 실시간 감시불가웹훅 수신 서버 필요. 브라우저는 백그라운드에서 대기할 수 없습니다.
다른 계정 자동 로그인·대리 게시불가플랫폼 약관 위반이며 계정 정지 위험. 앱은 ‘복사’까지만 합니다.
실시간 성과 스크래핑불가CORS·로그인·차단 정책. 화면에서 본 숫자를 입력하는 방식만 안전합니다.

표에 없는 기능은 되는지 확인되지 않은 것입니다. 확인 없이 “됩니다”라고 말하지 않습니다.

🧾데이터가 가는 곳

  • Gemini 키와 모든 작업물은 이 브라우저 localStorage에만 저장됩니다.
  • 외부로 나가는 요청은 Gemini API 한 곳뿐입니다(키가 있을 때). 폰트·이미지·분석 도구를 부르지 않습니다.

  • 브라우저 데이터를 지우면 작업물도 함께 사라집니다. 중요한 결과물은 PNG/ZIP/WebM/JSON으로 내려받아 두세요.
